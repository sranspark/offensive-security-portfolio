# Vikram Sran - Offensive Security Portfolio

Source for a recruiter-facing portfolio that connects authorized lab work to reproducible evidence, sanitized reports, and technical writing.

## Current focus

- Web application penetration testing
- Network and service enumeration
- Active Directory fundamentals and attack-path validation
- Linux privilege escalation
- Vulnerability reporting and remediation
- Security automation

## Evidence standard

Every public claim must originate from work performed against an owned system, an intentionally vulnerable application, an authorized training platform, or another explicitly authorized environment. Credentials, flags, private course content, and identifying infrastructure details are excluded.

## Development

```bash
npm install
npm run dev
```
